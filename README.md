# 🚜 All About Earth's Movement

## Καλλιόπη Μαριάκη & ΣΙΑ Ε.Ε.

Official website for **Καλλιόπη Μαριάκη & ΣΙΑ Ε.Ε.**, providing information about excavation, demolition, land development and related earthmoving services.

The website is available in both **Greek and English** and is designed to provide a responsive and modern experience across desktop, tablet and mobile devices.

---

## 🌐 Website

The website presents:

* 🚜 Excavation services
* 🏗️ Demolition services
* ⛰️ Land development and preparation
* 🌱 Garden soil / screened soil services
* 📸 Project gallery
* 📞 Contact information
* 🇬🇷 Greek / 🇬🇧 English language support

---

## ✨ Features

* Responsive design
* Desktop, tablet and mobile support
* Greek / English language switch
* Animated hero section
* Responsive service cards
* Project image slideshow
* Automatic slideshow rotation
* Fade transitions between images
* Previous / Next navigation
* Pause slideshow on mouse hover
* Keyboard navigation
* Smooth scrolling
* Modern visual design

---

## 🛠️ Technologies

The website was developed using:

* HTML5
* CSS3
* JavaScript
* Font Awesome

No frontend framework is required.
